# gruporadar-midia

Artes publicadas no Instagram @gruporadarsistemas e o kit que as gera.

- `ESTRATEGIA.md` — objetivos, público, pilares, grade e CTAs
- `ROTINA.md` — passo a passo das rotinas automáticas (diária e semanal)
- `PAUTA.md` — plano da semana
- `LOG.md` — tudo o que foi publicado
- `brand/` — cores, fonte, estilos e logos
- `templates/` — modelos de Story e post
- `tools/render.py` — HTML → JPEG no tamanho do Instagram
- `tools/reel.py` — quadros → Reel MP4
- `posts/` — cada publicação (HTML, imagens e legenda)
- `relatorios/` — relatórios semanais
